# ADR 001 — Phaser y vista isométrica

## Contexto

El propietario eligió pixel art 2.5D y navegador de PC. Se busca cuerpo completo animado, regiones amplias y rendimiento suficiente en el equipo de referencia.

## Decisión

Usar Phaser 4.2.1 como base investigada, TypeScript y Vite; React para interfaz fuera del canvas. Tiled definirá mapas y LibreSprite permitirá editar sprites.

Phaser tiene [soporte para mapas isométricos](https://docs.phaser.io/phaser-editor/scene-editor/game-objects/tilemap-object). La [versión de referencia](https://phaser.io/download/phaser4) fue verificada durante la investigación inicial.

## Consecuencias

La profundidad y oclusión requieren reglas explícitas. La simulación se mantiene en coordenadas lógicas y no depende de la proyección. El arte y las animaciones son una parte relevante del presupuesto de producción.

No se necesita un motor 3D ni exportar un ejecutable de escritorio.

## Revisión

Verificar compatibilidad de versiones al abrir implementación. Si falla el soporte de una función esencial, documentar el caso y actualizar el ADR antes de cambiar de motor.
