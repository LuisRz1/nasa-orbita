# Riesgos y respuestas

| Riesgo concreto | Respuesta | Señal que revisar |
| --- | --- | --- |
| Adelantar trabajo y afectar elegibilidad | Respetar preparación documental y registrar apertura. | Condiciones oficiales y horario. |
| Confundir campaña con demo | Mantener entregas separadas. | Una función esencial desplazada por contenido extra. |
| Producir demasiado arte para 48 horas | Priorizar una región y acciones básicas. | Atlas o animación bloquea recorrido completo. |
| Espacio amplio pero repetitivo | Diseñar problema y consecuencia por región. | Jugadores describen misiones como iguales. |
| Datos científicos excesivos | Seleccionar productos por uso y tamaño. | Build o descarga inicial excede presupuesto. |
| Inventario interrumpe exploración | Apilado y transferencia simple. | Exceso de tiempo en menús. |
| Chat falla o genera costes | Diálogo escrito completo y acceso gratuito comprobado. | Errores de cuota o acceso sin crédito gratuito. |
| Recompensas duplicadas | IDs y transiciones idempotentes. | Recargar cambia premios entregados. |
| Enunciado final cambia requisitos | Revisar el 28 de octubre. | Matriz preliminar deja un requisito sin cubrir. |
| Guardado pierde compatibilidad | Versionado, validación y respaldo. | Partidas de una entrega anterior fallan. |

Cada riesgo se convierte en tarea cuando requiere una acción. No registrar un riesgo como incidente ocurrido si solo es una posibilidad.
